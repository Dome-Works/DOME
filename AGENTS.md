# DOME Agent Entry Point

Before planning, reviewing, or changing this repository, read and follow all
requirements in [Instructions.md](Instructions.md).

The instructions apply to the entire repository. More specific `AGENTS.md`
files in subdirectories may add or override rules for that subtree.

When preparing release documentation (`CHANGELOG.md`, `README.md`, or GitHub
Release notes), follow `.cursor/skills/document-release/SKILL.md`.

Always prioritize these requirements:

1. Investigate the existing implementation and identify the root cause before editing.
2. Preserve the documented architecture and layer boundaries.
3. Make the smallest complete change that solves the requested problem.
4. Build and test the affected projects after making changes.
5. Never report completion while relevant build, lint, or test failures remain.
